# ant_universe
# 🪐 星尘蚁群：星系寻路 (Stardust Ant Colony)

一个将“蚁群寻路算法”与“3D 宇宙星云”结合的交互式网页。

**在线体验：** https://Tyytlym.github.io/ant_universe/

---

## 🌌 玩法说明

1. **点击屏幕**：在深空中投放高能“星糖”。
2. **观察星尘**：暗蓝色的星尘会变成青色，像流星一样冲向星糖；吃到糖后变成耀眼的品红色，拖着辉光飞回中心的黑洞。
3. **拖拽鼠标**：可以旋转 3D 视角，从不同角度观察星系运转。

---

## ✨ 技术特点

- 基于 **Three.js (WebGL)** 实现真 3D 空间。
- 纯手写 **GLSL Shader** 渲染粒子光晕。
- 引入 **UnrealBloom** 后期处理，实现影视级的辉光发光特效。
- 中心黑洞由 3000 颗旋转粒子构成，深邃且立体。

---

## 💻 本地运行

无需安装，直接双击打开 `index.html` 即可。

*(注：本项目依赖 Three.js 的 CDN，请确保网络畅通。)*
